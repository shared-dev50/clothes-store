# HBS Wear

Ecommerce website for HBS Wear.

## Tech Stack

* React + Vite + TypeScript
* Node.js + Express + TypeScript
* PostgreSQL + Prisma

## Clone Repository

git clone https://github.com/shared-dev50/clothes-store.git
cd clothes-store

## Run Locally

### Frontend

```bash
cd client
npm install
npm run dev
```

Frontend: `http://localhost:5173`

### Backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

Backend: `http://localhost:5000`

## Database

Create `server/.env` using `server/.env.example` and configure the PostgreSQL connection.
